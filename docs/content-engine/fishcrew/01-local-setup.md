# Local PC setup — download checklist

Install these on your machine. Nothing here requires Claude.

## Required

| Tool | Why | Get it |
| --- | --- | --- |
| **CapCut** (desktop or phone) | Edit Reels fast: captions, hooks, cuts | [capcut.com](https://www.capcut.com/) |
| **ChatGPT or Gemini** (free is fine) | Script polish, caption variants | chatgpt.com / gemini.google.com |
| **Instagram** (phone) | Post Reels + Stories | App Store / Play Store |
| **ManyChat** (Free plan) | Auto-DM when someone comments a keyword | [manychat.com](https://manychat.com/) |

## Strongly recommended

| Tool | Why | Get it |
| --- | --- | --- |
| **Canva** | Lead-magnet PDF / carousel pages | [canva.com](https://www.canva.com/) |
| **Google Drive or Notion** | Store scripts + lead magnets | — |
| **Phone with good daylight video** | Face-to-camera or B-roll of tackle/water | — |

## Optional later (not day 1)

| Tool | When to add |
| --- | --- |
| Claude Pro + ViewMax MCP | Only if you want one-chat video generation |
| ElevenLabs | AI voiceovers for faceless clips |
| Metricool / Later | Scheduling once you’re posting daily |

## Account setup order (30–45 min)

1. Create/claim Instagram: `@fishcrew` if available, else `@fishcrew.app` / `@getfishcrew` (match bio link).
2. Bio:
   ```
   Your water, your crew, your window.
   Tampa Bay → FL bite windows + crew matching
   ↓ Free morning checklist
   ```
3. Link in bio → `https://fishcrew.macksims.com/?utm_source=ig&utm_campaign=bio`
4. Connect Instagram Business/Creator account to ManyChat.
5. Build one automation (see `04-funnel-manychat.md`) for keyword `TIDE`.
6. Drop lead magnet PDF into the DM (or Google Drive link).

## Filming kit (minimum)

- Phone + quiet outdoor or garage wall
- Natural light facing you
- Optional: cheap lav mic / DJI Mic
- Props: rod, shrimp packet, leader spool, pliers, tide screenshot from FishCrew

## Folder layout on your PC

```
FishCrew-Content/
  scripts/          ← copy from 03-reel-scripts-week1.md

  broll/            ← water, tackle, pier, kayak clips
  exports/          ← final MP4s from CapCut
  captions/         ← pasted IG captions
```
